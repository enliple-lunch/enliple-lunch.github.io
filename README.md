# 🍚 오늘 뭐 먹지? · 한신아이티타워 점심지도

서울 구로구 디지털로 272(한신아이티타워) 기준 **반경 500m** 식당 지도 + 날씨 맞춤 점심 추천 + 직원 익명 후기.

## 👉 [사이트 바로가기](https://enliple-lunch.github.io/) (모바일 OK)

## 기능

- **오늘의 날씨**: 기온 · 체감 · 강수확률 · 습도 · 바람 · 미세먼지/초미세먼지 (Open-Meteo)
- **날씨 맞춤 추천**: 비/눈/한파 → 국물·탕 + 가까운 곳 / 선선 → 멀리 가도 OK / 더위 → 냉면·회·샐러드 + 가까운 곳
- **오늘의 점심**: 날짜 시드라 하루 동안 고정, `🎲 다시 뽑기`로 재추첨
- **네이버 평점 · 방문자 리뷰 · 블로그 리뷰** 표시, 카드의 🟢 버튼 → **네이버지도 바로 이동**
- **회사에서의 거리**(직선) + 도보 시간
- **직원 익명 후기**: 가상 닉네임(예: "배고픈 판다") + 160개 이모지 프로필, 8종 한 방 평가(👍🔥😋🍽️💸🫶😐👎)
- **월간 랭킹**: 이달의 맛집(먹었어요×3 + 후기×2 + 좋아요) · 후기왕 · 출석왕 · 새로 생긴 곳, 지난달 보기
- **밝은/어두운 테마** 전환 (기본 밝게)
- **맛집 추가 요청**: 리스트에 없는 가게를 이름만 적어 요청 → 다음 날 아침 자동 갱신 때 카카오맵에서 찾아 반경 500m 안이면 자동 추가 (상태: 대기중/추가됨/반경 밖/못 찾음)
- **최근 후기 피드**: 메인에서 방금 올라온 후기 모아보기
- 필터: 종류 · 카테고리 · 거리 · 예산 · 신규 / 정렬: 거리 · 네이버 리뷰 · 평점 · 가격

## 추가 기능
- **점심시간 13:00~14:00 기준**: 점심 카운트다운, 12~15시 시간별 날씨, 투표 마감 12:30/12:45/13:00
- **🎯 이달의 미션**: 개근왕🔥 탐험가🧭 미식가🌏 리뷰어✍️ 개척자👑 회식러🍻 얼리어답터🆕 방콕러🏢 → 달성 시 닉네임 옆 배지
- **🆕 신규 오픈 배너**, **☔ 비 오는 날 모드**(13시 강수확률 60%↑ 또는 비/눈이면 "200m 이내만" 버튼)
- **📸 사진 올리기**: 사진 없는 가게에 직원이 첫 사진 등록 (자동 축소, Firebase 저장)
- **🏢 층별 가이드**: 주소에서 건물·층·호수 추출, "🏢 우리 건물" 칩
- **⭐ 즐겨찾기 + 🗺️ 맛지도 공유**: 폴더별 저장, 맛지도 링크(#fmap=코드)는 한 번 보내면 자동 업데이트

## 자동 갱신

`.github/workflows/update.yml` 이 **매일 09:20 KST**에 `scripts/update.mjs`를 실행:
1. 카카오맵 검색 125개 키워드로 반경 500m 식당 + 메뉴/가격 재수집 (키워드당 90개 제한 우회)
1-2. 직원 추가 요청(Firebase `/requests`) 처리 → 찾으면 리스트에 편입, 검색에서 안 나와도 계속 유지
2. 네이버 플레이스 매칭(평점·리뷰수·플레이스ID). 실패하면 이전 값 유지
3. 처음 발견한 날을 `seen.json`에 기록 → 14일간 `🆕 신규` 배지 (검색에서 하루 빠져도 7일간 유지)
4. `data.js` + `index.html` 커밋 → Pages 자동 재배포

수동 실행: **Actions → 점심지도 데이터 갱신 → Run workflow**

## 후기 저장소

Firebase Realtime Database (`guro-lunch`, asia-southeast1, 무료 Spark)
- 누구나 쓰기/읽기 가능 (로그인 없음), 글자수 300자 제한
- 남의 글 수정 불가, 삭제는 작성한 브라우저에서만 버튼 노출
